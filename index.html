03 · KONSEP ASAS

Apakah algoritma?

Algoritma ialah satu set langkah yang disusun mengikut urutan untuk menyelesaikan sesuatu masalah.

Algoritma membantu menentukan tindakan yang perlu dilakukan, langkah demi langkah.

05 · FOKUS PEMBELAJARAN

Struktur kawalan pelbagai pilihan

Mengandungi lebih daripada dua set tindakan yang berlainan sebagai pilihan untuk dilaksanakan.

Set tindakan yang dilaksanakan bergantung kepada pilihan syarat yang didapati benar.

SYARAT 1

Benar?

Set tindakan A

SYARAT 2

Benar?

Set tindakan B

SYARAT 3

Benar?

Set tindakan C

JIKA TIDAK

Tiada syarat benar

Set tindakan D

Rujukan: Buku Teks ASK Tingkatan 1, Rajah 3.12, muka surat 76.

07 · IKUTI ALIRAN KEPUTUSAN

Bagaimana syarat diuji?

LANGKAH 1

Uji syarat 1

YA → tindakan A. TIDAK → syarat 2.

LANGKAH 2

Uji syarat 2

YA → tindakan B. TIDAK → syarat 3.

LANGKAH 3

Uji syarat 3

YA → tindakan C.

JIKA SEMUA TIDAK

Tindakan D

Laksanakan tindakan D sebagai pilihan terakhir.

09 · CONTOH BUKU TEKS

Menentukan gred murid

Skor yang dimasukkan menentukan gred melalui lima syarat berurutan: skor ≥ 80, ≥ 70, ≥ 60, ≥ 50 dan ≥ 40. Jika semuanya tidak dipenuhi, gred ialah F.

GredSkor
A80–100
B70–79
C60–69
D50–59
E40–49
F0–39
🏅

Contoh skor: 90

Skor 90 memenuhi syarat skor ≥ 80.

GRED A

Jadual 3.2 dan Rajah 3.14, muka surat 77.
