Apakah algoritma?

Algoritma ialah satu set langkah yang disusun mengikut urutan untuk menyelesaikan sesuatu masalah.

Algoritma membantu menentukan tindakan yang perlu dilakukan, langkah demi langkah.

05 · FOKUS PEMBELAJARAN

Struktur kawalan pelbagai pilihan

Mengandungi lebih daripada dua set tindakan yang berlainan sebagai pilihan untuk dilaksanakan.

Set tindakan yang dilaksanakan bergantung kepada pilihan syarat yang didapati benar.

07 · IKUTI ALIRAN KEPUTUSAN

Bagaimana syarat diuji?

LANGKAH 1

Uji syarat 1

YA → tindakan A. TIDAK → syarat 2.

LANGKAH 2

Uji syarat 2

YA → tindakan B. TIDAK → syarat 3.

LANGKAH 3

Uji syarat 3

YA → tindakan C.

JIKA SEMUA TIDAK

Tindakan D

Laksanakan tindakan D sebagai pilihan terakhir.

09 · CONTOH BUKU TEKS

Menentukan gred murid

Skor yang dimasukkan menentukan gred melalui lima syarat berurutan: skor ≥ 80, ≥ 70, ≥ 60, ≥ 50 dan ≥ 40. Jika semuanya tidak dipenuhi, gred ialah F.

GredSkor
A80–100
B70–79
C60–69
D50–59
E40–49
F0–39
🏅

Skor 90 memenuhi syarat skor ≥ 80.

BONUS MISSION 02 · DETECTIVE MODE

Algorithm Detective

Baca algoritma. Ramalkan output bagi setiap input.

ALGORITMA SUHU
INPUT suhu
IF suhu >= 35
  OUTPUT "PANAS"
ELSE IF suhu >= 25
  OUTPUT "SEDERHANA"
ELSE
  OUTPUT "SEJUK"
END IF

Mengapakah syarat suhu ≥ 35 diperiksa dahulu sebelum suhu ≥ 25?

Terangkan berdasarkan susunan syarat.

SOALAN 5 · 3 MARKAH

Tentukan gred bagi markah 75, 55 dan 30.

A ≥ 80 · B ≥ 60 · C ≥ 40 · F selainnya

🔑 Paparkan skema jawapan guru

1. SEDERHANA · 2. SEJUK · 3. PANAS. Soalan 4: Syarat tertinggi diperiksa dahulu supaya nilai yang memenuhi syarat itu tidak tersalah dikelaskan oleh syarat yang lebih rendah. Soalan 5: 75 = B, 55 = C, 30 = F.

TUGASAN 3 · DEBUGGING

Kenal pasti kesilapan dan tulis semula dengan betul.

INPUT markah
IF markah >= 80
  OUTPUT "A"
ELSE
  OUTPUT "B"
ELSE IF markah >= 50
  OUTPUT "C"
END IF
🔑 Paparkan panduan jawapan guru

Tugasan 1: IF warna = "MERAH", ELSE IF warna = "KUNING", ELSE IF warna = "HIJAU", ELSE paparkan "INPUT TIDAK SAH", kemudian END IF. Tugasan 2: MULA → input jenis_pengangkutan → tiga keputusan mengikut pilihan → tindakan alternatif → TAMAT. Tugasan 3: ELSE tidak boleh diletakkan sebelum ELSE IF. Susun semua ELSE IF dahulu dan letakkan ELSE sebagai pilihan terakhir. Contoh: markah ≥ 80 → A, markah ≥ 50 → C, selainnya → B (atau tetapkan kategori yang dikehendaki sebelum membina algoritma).

CABARAN 3 · 3 MARKAH

Mengapakah ELSE diperlukan?

Jelaskan fungsi tindakan alternatif dan kemungkinan yang berlaku jika ELSE tidak disediakan.

🔑 Paparkan skema jawapan guru

1. Murid B. Syarat ≥ 80 perlu diuji dahulu. Dalam algoritma A, markah 80 ke atas sudah memenuhi ≥ 50, maka output CEMERLANG tidak akan dicapai. 2. INPUT mata → IF mata ≥ 100 OUTPUT 3 BINTANG → ELSE IF mata ≥ 70 OUTPUT 2 BINTANG → ELSE IF mata ≥ 40 OUTPUT 1 BINTANG → ELSE OUTPUT TIADA BINTANG → END IF. Carta alir mengikut urutan sama. 3. ELSE menyediakan tindakan alternatif apabila semua syarat terdahulu tidak dipenuhi. Tanpanya, keadaan tersebut mungkin tidak mempunyai tindakan yang ditetapkan.
